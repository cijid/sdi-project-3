# Project Title - Joint Space Tactical Awareness and Reporting

## Overview

This project is to provide coordination between Army users and Space Force operators. <br />
Army operations depend heavily on satellite communications (SATCOM) and Positioning, Navigation and Timing (PNT) across essentially every warfighting function, while current Space Force planning emphasizes making PNT/SATCOM status and degradation understable and usable by the Joint Force.<br />

The goal is to provide an answer to "What space-enabled capabilities do I have right now, what is degraded, and what should I do about it?" and make those answers useful to an Army staff.

The MVP is two separate dashboards:
Space Force Operator: Create an effect/degradation report with capability, location/area, severity, start/end time, confidence, description and recommended action.

Army User: See a dashboard of current effects and filter by location/capability.

Guardians enter space-domain information, but Soldiers see operational consequences.

Stretch Goal: Workflow that allows Army users to create tickets when something involving space isn't working.
