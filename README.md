# Project Title - Mouth Sounds

## Overview

This project is an educational web application designed to help my son practice English and Cantonese language skills. <br />
The English portion of the application will include sight-word flash cards and a timed letter-sound recognition game. <br />
The Cantonese portion will focus on phoneme recognition and pronunciation using audio recordings. The application will organize these recordings so they can be easily referenced and retrieved during practice activities.
